# Living Off the Pipeline

Materials for the presentation and its self-contained CI/CD security lab.

## Repository layout

```text
presentation/
  Living-Off-the-Pipeline.pptx   Approved presentation
  recordings/                    Embedded-video source recordings

lab/
  README.md                      Lab setup and operation
  WALKTHROUGH.md                 Scenario entry point
  compose.yaml                   Container environment
  config/                        Runner configuration
  demo/                          Application and scenario files
  docker/                        Gitea and runner images
  docs/                          Lab documentation
  observability/                 Events and detection examples
  scripts/                       Start, reset, status, and stop commands
  walkthroughs/                  Scenario instructions
```
